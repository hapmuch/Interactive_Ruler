name=Interactive-Ruler
description=Interactive ruler with a launcher dialog, straight-line and multi-point path measurement, a layer-name box that groups measurements as distance-named layers, direction arrows and length labels
about=Interactive ruler for QGIS. Draw straight lines or multi-point paths on the map and save each measurement as its own styled ruler layer with direction arrows and a length label. Measurements are grouped under a layer name and named after their result (for example SITE A 1.82 km), with automatic metre/kilometre units, a live distance balloon while dragging, adjustable label font size and line width, and three colour themes: Dark, Light and Red (#e31a1c). Existing lines keep their own style and are never recoloured.

changelog=1.18 - Qt6 compatibility fixes: enum members are now scoped (for example Qt.MouseButton.LeftButton and QgsUnitTypes.RenderUnit.RenderMillimeters), exec_() is replaced by exec(), and QVariant is imported from qgis.PyQt. No behaviour change. 1.17 - Added a Red theme (#e31a1c) alongside Dark and Light. The live rubber band shown while dragging is now always red, so the preview stays visible with the Light theme too. 1.16 - The ruler now refuses to measure when the project has no CRS and shows a warning instead ("Set a project CRS before measuring"). Previously the canvas units were interpreted as metres, producing a meaningless length. No pending layer is created until a project CRS is set. 1.15 - Fixed a RuntimeError when a pending ruler layer was deleted outside the plugin (removed in the Layers panel, project closed) and the tool was then deactivated: the layer id is now tracked and every access guarded, so an empty name group is still cleaned up. Drawing after such a deletion starts a fresh pending layer instead of touching the deleted object
