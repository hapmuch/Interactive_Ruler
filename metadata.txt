changelog=1.17 - Added a Red theme (#e31a1c) alongside Dark and Light. The live rubber band shown while dragging is now always red, so the preview stays visible with the Light theme too. 1.16 - The ruler now refuses to measure when the project has no CRS and shows a warning instead ("Set a project CRS before measuring"). Previously the canvas units were interpreted as metres, producing a meaningless length. No pending layer is created until a project CRS is set. 1.15 - Fixed a RuntimeError when a pending ruler layer was deleted outside the plugin (removed in the Layers panel, project closed) and the tool was then deactivated: the layer id is now tracked and every access guarded, so an empty name group is still cleaned up. Drawing after such a deletion starts a fresh pending layer instead of touching the deleted object
